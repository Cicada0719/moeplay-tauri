## Default Permission

Allows MoePlay to detect installed emulators, launch ROMs via intents, and request all-files access on Android handhelds.

#### This default permission set includes the following:

- `allow-list-emulators`
- `allow-launch-game`
- `allow-has-all-files-access`
- `allow-request-all-files-access`
- `allow-discover-rom-roots`
- `allow-set-system-bars`
