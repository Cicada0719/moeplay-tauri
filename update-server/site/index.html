    BEFORE YOU UPDATE

    升级前，选对你的版本。

    Windows

    推荐 EXE 安装版。官方更新使用签名校验；MSI 和便携 ZIP 见上方完整列表。便携版请解压后运行。

    Android 正式 / 兼容

    正式 Release 包使用长期证书。旧 Debug 用户需选择旧签名兼容包，两种证书不能互相覆盖。

    兼容升级测试状态以发布清单为准。切换签名渠道前，先导出阅读历史。

    阅读备份

    在“统一历史”导出 JSON，新安装后再导入。只备份漫画与小说的本地阅读记录，不包含游戏库、源凭据或完整应用数据。
