# Task 08：同步写入保护与能力说明

## 目标与依赖

在不扩展完整跨设备同步模型的前提下，修复现有 WebDAV/SQLite 链路的危险写入和错误说明。依赖 Task 07 的本地备份语义。

## 允许修改

`src-tauri/src/sync/{mod,webdav,merge}.rs`、`db_sqlite.rs` 同步辅助函数、SyncSettings 文案与测试。禁止把 IndexedDB 阅读历史直接接入同步；禁止修改播放器、离线库和规则文件。

## 行为

- 412 后重拉必须带最新 ETag 条件 PUT；第二次仍冲突则失败，不能 `None` 无条件覆盖。
- 新建远端文件使用防覆盖条件；认证、网络、解析失败均不落库、不清空本地。
- 合并键至少加入 `content_type`，同秒冲突使用稳定 tie-breaker；保留旧协议字段兼容，暂不设计章节级同步。
- 单事务落库时保护同步期间新写入的本地记录。
- 设置页准确说明当前只同步 SQLite/已接入范围，不能宣称三类 IndexedDB 历史已跨设备接力。

## 验收

连续两次并发 412、同 ID 不同类型、同步中新增、认证失败、损坏远端 JSON 和断网恢复均不丢有效记录；同一输入多次合并结果一致；相关 Rust 集成测试通过。
