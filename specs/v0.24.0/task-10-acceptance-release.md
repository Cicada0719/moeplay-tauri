# Task 10：全量验收与 v0.24.0 发布

## 目标与依赖

依赖 Task 01–09 的合入和证据。只负责测试、文档、版本和发布，不在此任务修功能缺陷。

## 允许修改

验收脚本/测试、版本文件、README、CHANGELOG、回归报告和发布配置中必要的只读校验接入。禁止修改前置任务功能代码、覆盖既有 tag/附件或跳过真实设备限制。

## 验收矩阵

- 全量前后端测试、`verify:commands`、版本一致性、fmt、Clippy、Svelte check、构建和视觉回归。
- 播放首帧、持续播放、快进、切集、换源、后台恢复、退出无残留音频；错误报告区分应用/网络/上游。
- 追番首次基线、增量提醒、未看数、已看和同季隔离。
- 离线漫画图片和小说正文：下载、中断、断网、重启、删除、空间统计和续读。
- 三类历史导入导出、坏记录、重复导入和存储故障。
- 漫画第 12 话第 7 页；小说第 30 章 45% 恢复误差 ≤5%；小说超过 60 章其他书仍存在。
- Windows 安装/升级；Android Release 冷启动、Compat 覆盖升级和掌机按键。未连接实机的项目标为未执行。

## 发布顺序

1. 更新所有版本文件为 `0.24.0`，写 CHANGELOG 和回归报告。
2. 冻结一个发布提交并生成该提交的 Windows/Android 产物、manifest、签名、SHA-256；不在上传过程中重建。
3. 本地验收完成后推送 `feat/issue-<编号>`，等待 CI 明确 `completed/success`，再合并并创建 v0.24.0 GitHub Release。
4. 将同批产物部署到 `https://moeplay.sgy0719.top` 和 `192.168.2.88:8788`；旧版本目录保留，current 原子切换。
5. 验证主页 200、`latest.json` no-store、五个主文件哈希、HTTP 206、更新签名和回滚路径；报告区分已验证、受限和未执行。

## 完成条件

所有阻塞验收通过；发布清单与提交 SHA 一致；GitHub 和下载站使用同批文件；旧版本可下载；无 P0/P1 未记录问题。任何第三方源失败不得伪装成应用已验证成功。
